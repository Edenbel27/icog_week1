Tic Tac Toe AI Using Minimax and Alpha-Beta Pruning
1. Introduction

This project implements a Tic Tac Toe game in Python where a human player competes against an AI.
The AI uses the Minimax algorithm and Alpha-Beta pruning to make optimal decisions.

The purpose of the project is to:

- understand game trees
- implement the Minimax algorithm
- improve performance using Alpha-Beta pruning
- compare node exploration between plain minimax and pruning

2. Implementation

- Board Representation:

The board is represented using a list of 9 elements: board = [" "] * 9

Each position stores:

"X" for the human player
"O" for the AI
" " for an empty space

- Move Generation

Possible moves are generated by checking empty spaces on the board.

for i in range(9):
    if board[i] == " ":

The program has a function called best_move to select the next best move for the agent.

- Win and Draw Detection

The program checks all possible winning combinations: rows, columns, diagonals using the check_winner() function.

The is_draw() function checks whether the board is full without a winner.

- Minimax Algorithm

The Minimax algorithm recursively explores all possible game states.

The AI (O) acts as the maximizing player.
The human (X) acts as the minimizing player.

Scores used:

AI win = +1
Human win = -1
Draw = 0

The algorithm chooses the move with the best possible outcome.

- Alpha-Beta Pruning

Alpha-Beta pruning was added to improve efficiency.

Two values are maintained:

alpha → best value found by the maximizing player
beta → best value found by the minimizing player

Pruning occurs when: β≤α

This prevents unnecessary exploration of branches that cannot affect the final decision.

3. Results

The AI was able to play optimally and never lose.

The node count comparison showed that Alpha-Beta pruning explored significantly fewer nodes compared to plain minimax.

Example observation:

Nodes with pruning: 2,000
Nodes without pruning: 15,000

This demonstrates that Alpha-Beta pruning improves performance while producing the same optimal move.

4. Conclusion

This project successfully implemented:

board representation
move generation
win/draw detection
Minimax algorithm
Alpha-Beta pruning

The experiment showed that Alpha-Beta pruning reduces the number of evaluated nodes and improves efficiency without changing the final decision made by the AI.
